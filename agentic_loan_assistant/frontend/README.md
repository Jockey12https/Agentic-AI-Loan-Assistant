# Agentic Loan Assistant - Next.js Frontend

Modern React frontend built with Next.js for the Agentic Loan Assistant application.

## Features

- 🎤 Voice recording using Web Speech API
- 💬 Text-based chat interface
- 🎨 Modern, responsive UI
- ⚡ Fast and optimized with Next.js
- 🔄 Real-time chat with multiple agents

## Getting Started

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

The frontend will be available at [http://localhost:8080](http://localhost:8080)

### Build for Production

```bash
npm run build
npm start
```

## Requirements

- Node.js 18+ 
- Backend server running on http://localhost:8000

## Browser Support

- Chrome/Edge (recommended for voice features)
- Firefox
- Safari

Note: Web Speech API is best supported in Chrome and Edge browsers.
